## 缺陷

### D1【P2】桌面侧栏「历史会话」没有重命名 / 删除入口
- **步骤**：登录 → `/chat` 创建会话 → 左侧「历史会话」出现 1 条 → 查找行内改名/删除。
- **预期**：会话项可重命名、可删除（源码里已有实现：`ConversationView.vue:756-795` 有 `重命名会话/删除会话` 按钮、确认弹层「删除后不可恢复」）。
- **实际**：部署版桌面侧栏由 `DesktopSidebar.vue:95` 渲染，会话项是单个 `desk-session` 按钮（仅点击进入），DOM 中**不存在** `[aria-label^="重命名会话："]` / `[aria-label^="删除会话："]`（`probe-session-ui.json`：`rename:[]、del:[]`；`session-ui2.json` 同样）；页面其它位置也无入口。
- **后端/同步正常**：API `PATCH /app/sessions/{id}`→200 且刷新后标题变化；`DELETE`→200 且列表移除、重复删除 404（`api2-sec.json` SESSION-02/03/04/05/06）。
- **影响**：用户只能通过 API 改名/删除会话；界面无可发现的入口，功能“有实现但不可达”。
- **建议**：把 `ConversationView` 的会话管理（搜索/行内重命名/删除确认）挂到桌面侧栏 session 行（hover 显示操作）或在会话卡提供入口；移动端同步。
