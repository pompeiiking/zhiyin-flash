## 逐项修复

### #35 未知 `task_id` 静默创建会话

- 根因：`DialogueRuntime.run` 在 `session is None` 时按 `free_chat` 直接创建会话，且不受服务端签发约束。
- 修复：未知会话直接返回 404「会话不存在或已失效，请从任务入口重新进入」；归属不符返回「会话不属于当前账号」。会话只能由 `POST /app/task/enter` 创建。
- 回归：`test_unknown_task_id_is_rejected_and_never_creates_a_session`。

### #38 跨字段 supersede 与失败后的死提案

- 根因：取代条件只校验 `operation`，不校验画像 `key`；新提案执行失败后旧提案仍永久停在 `superseded`；同一轮批量写入时，第一条画像写入会改变整份画像版本，后续字段被版本校验判成「数据已变化」。
- 修复：
  - `profile.update` 的取代必须指向同一 `key`，跨字段取代直接拒绝；
  - 新提案记录 `supersedes_action_id`；执行失败（版本变化、取消、校验失败、未知结果）时，把被取代的旧提案恢复为 `proposed`，避免一次失败连带吞掉上一条可用提案；
  - 画像写入的版本校验改为只比较目标字段自身的时间戳，同轮不同字段互不失效；
  - 账本保留 `superseded_by` 追踪链。
- 回归：`test_cross_field_supersede_is_rejected_and_old_proposal_survives`、`test_automatic_batch_profile_writes_do_not_invalidate_each_other`。

### #41 未通过内容校验的报告仍保存成功版本

- 根因：`report.save` 只有结构校验；无效结论只在 API 展示层被替换成「本版结论待重新生成」，落库与对话回执都仍是成功。
- 修复：
  - 新增 `zhiyin_kernel.report_quality.report_verdict_issue`，拒绝空结论和混入「本报告 / 本轮 / 上一版 / 更新的是依据」等生成过程评论；
  - 在 `validate_action`、执行落库、`DefaultAssetService.save_report` 三处共用同一护栏，未通过的产出不生成版本；
  - API 展示层复用同一份标记表，只兜历史存量。
- 回归：`test_meta_commentary_report_is_rejected_before_saving_a_version`、`test_valid_report_still_saves_a_draft`。

### #39 画像有值、采集清单却显示未获取

- 根因：`CollectionStep` 只有 `got` 布尔值，`conversation` 来源的权威字段被算作 `got=false`，界面无法区分「完全没拿到」和「已有本人自述、待核实」。
- 修复：
  - 采集项增加 `state=missing|unverified|got`、`value`、`field_source`、`verification`、`status_text`、`confirmable`；
  - 采集面板增加 `unverified` 计数，`got` 仍按来源相称计算，不把自述伪装成已核验；
  - 画像页新增「已有你的自述，待核实」分组，提供「确认这个值」与「去学信网核验」两个入口；确认走既有本人更正接口，落为 `user_edit / user_confirmed`，下一轮采集即算拿到。
- 回归：`test_conversation_value_on_authoritative_field_is_unverified_not_missing`。

### #40 否定项进入兴趣、同一概念重复

- 根因：`merge_preferences` 把 dislike 项也放进 `interest.value`，且只按字符串精确相等去重；本地仓库 `upsert_field` 在值相同、仅属性变化时提前返回，导致极性修正被静默丢弃。
- 修复：
  - `interest.value` 只保留 like/unsure，否定项保留在逐项属性 `attributes.items` 的 `polarity=dislike` 中；
  - 同极性、同一概念（一个短语包含另一个，如「应酬」/「天天应酬」）只保留更具体的说法；
  - 首次写入也走同一套拆分，不再只在第二轮合并时生效；
  - 本地仓库 `upsert_field` 比较属性后再判断幂等，属性变化不再被吞掉。
- 回归：`test_interest_split_negative_items_and_deduplicates_same_concept`、`test_same_concept_negative_phrases_are_deduplicated_without_entering_interest`。
