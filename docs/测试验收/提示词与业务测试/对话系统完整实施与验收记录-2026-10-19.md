# 对话系统实施与验收记录

日期：2026-10-19。对象：正式 Vue 前端与模块化单体后端。基于用户确认的[专项设计](../../产品与架构/对话系统重构设计-2026-10-19.md)实施；本记录区分代码交付、确定性测试、真实模型检查和部署验证。

## 交付内容

| 设计要求 | 实现位置与结果 |
| --- | --- |
| 普通咨询自然回答，AI 自主选择工具 | `dialogue_runtime.py`、`impl/dialogue_engine.py`：独立自然正文与原生工具循环；不经过关键词、阶段强制、角色交接或固定收尾 |
| 近期上下文与短回答 | 使用完整历史消息及当前输入；当轮理解不以画像是否保存为前提；当前事实和明确纠正优先 |
| 较早上下文 | 40 条以上按需分层摘要，事实、决定、建议、假设、未解决事项分开；保留原消息 ID；摘要不提供操作授权 |
| 按需读取原文与跨会话上下文 | `workspace.read` 的 sessions/history；校验用户归属、来源偏好与“不自动记忆”设置；历史内容不是新增授权 |
| 读取无需审批 | 画像、成绩、报告、方向、计划、日历、记录、行为及获授权模块直接读取；学职平台和知识库仍按真实可用性调用 |
| 必要自动写入 | 肯定本人自述、原话证据、字段白名单、自动记忆偏好及版本检查；否定、引述、假设不写；课名咨询不自动变成学校课表 |
| 常规明确写入 | 明确更正画像、唯一任务状态、小范围明确任务调整、新资产草稿；调用既有业务服务和影响面、行为、缓存链 |
| 重要操作审批 | 替换生效资产、主动或批量修改、日历新增/删除、记忆删除、撤销；持久化具体参数、原版本、30 分钟有效期与绑定按钮 |
| 调整、重复和冲突 | 新提案可指定替代旧提案；重复请求回放；重复确认不重放；数据改变使原提案失效；未知结果不盲重试 |
| 草稿与生效分离 | 既有生效计划、报告、方向保留；新稿保存后另行批准启用；生成计划不默认写日历 |
| 流式正文与真实状态 | 原生文字增量、独立工具开始/完成/失败、记忆整理和摘要状态；协议带 run/session/sequence；无定时假进度 |
| 刷新和停止 | 运行查询、显式取消后续步骤、后台回读；断线不强行中断已开始写入；陈旧运行提示核对；会话删除先停止再串行清理 |
| 审计与存储 | 运行、操作、原话依据、目标版本、真实回执；模型与提示词指纹、受控读取参数；JSONB 记录显式按时间排序 |
| 记忆管理 | 账号自动记忆开关、会话“不自动记忆”、明确更正、删除及删除后防复活；删除使旧上下文摘要失效 |
| Kev | 按需 workspace.classify，3 秒上限；输出只作建议，无审批或写权限；失败后主对话继续 |
| 既有业务和平台 | 保留来源守卫、专用 AI 任务、业务服务、资产依赖、行为与完成记录、模块只读和既有发布动作边界 |

生命周期控制位于业务层 `conversation_control.py`，API Facade 只转发与映射，不直接处理仓储。API 新增运行查询、取消和会话设置，已同步 OpenAPI、前端类型和接入清单。

## 明确的实施参数

- 单轮总处理上限 150 秒；主对话工具上限 12 次；Kev 上限 3 秒；其他只读工具单次 8 秒；记忆提取及摘要配置各 12 秒。只读限时不套在写入与回执之间。耗时包含真实模型及外部工具，不承诺每轮固定延迟。
- 近期最多读取 100 条原文，以中英文混合的保守令牌估算控制约 12000 的历史预算，保留完整消息。它不是某一模型精确 tokenizer 的读数。较早摘要每项不超过 200 字、最多 20 项，保留最近 16 条作为原文候选；较长原文可按需读取。
- 历史读取每页 20 条，当前工具窗口最多 200 条；跨会话列表最多 50 条。已有摘要可跨窗口持续合并；尚未被摘要覆盖的更早内容不能宣称已经完整记住。
- 审批 30 分钟后过期；多个提案的含糊自然语言批准不执行，使用具体按钮或先明确对象。
- 热运行记录保留最近 32 份完整结果和轨迹；旧结果从持久化消息 metadata 回放，幂等标识继续保留，不能因压缩再次执行写入。操作记录继续保留到会话删除。
- 本次提供“不自动记忆”模式，不宣称浏览器关闭即删除或完全不留痕。历史、摘要及回执保留到用户删除会话；已主动保存的业务资产单独保留。界面已说明，未引入未告知的自动清库任务。
- 用户要求删除记忆时，清除对应画像并重置此前对话上下文，禁止旧原文、摘要、旧提取结果自动复活；其他已保存画像保留，聊天原文与业务资产的删除仍是独立操作。审批卡明确说明这一上下文重置影响。审计与备份不作为模型的可读记忆入口。

## 旧代码与测试迁移

移除 `routing_rules.py`、`conversation_policy.py`、`tool_offers.py` 和旧轻量对话契约；从 `orchestrator.py` 清理 3500 余行旧对话管线，包括关键词写入、句尾确认猜测、固定阶段、回复重写和旧私有捷径。保留的阶段/交接端口用于既有后台业务，不再控制前台每轮对话。

删除 15 个只绑定旧路由、旧私有助手或强制阶段输出的测试文件；混合文件保留成绩导入、材料、来源、可视件、影响面、平台权限等有效测试。替换覆盖位于 `test_dialogue_runtime.py` 和 `test_conversation_stream_text.py`，包含新授权矩阵、真实服务副作用、失败未知、持久化回放、草稿、生效、撤销、删除、摘要、来源隔离及原生文字流。

测试数下降来自行为变更和旧私有测试退役，不能据此声称覆盖率提高。原有业务回归仍纳入完整 pytest 执行；脚本模型仅用于确定性边界，不用作自然交流成功的证据。

## 验证结果

- 完整后端回归：最终业务链版本 1035 项通过，1 条既有 Starlette 依赖弃用警告；业务闭环重点回归 99 项通过，含真实发言、方向变更、明确计划调整与撤销、缓存隔离。流式同时验证服务端生成的运行标识不会被客户端空值覆盖。
- 前端：78 项通过，后端契约检查和正式构建通过；Impeccable 检查无发现。
- 独立 PostgreSQL schema：跨工作进程幂等回放、单连接池并行查询、画像与 outbox 事务回滚、过期字段版本不能删除新值，4 项检查通过；未清空或重置现有业务库。
- DeepSeek 实际调用：最终业务链修订后的 14 轮连续咨询、短回答、否定、时间限制、实际建计划、任务完成、新稿、审批启用、恶意文字分析前后数据比较和长会话摘要回忆检查全部通过。核心源码 SHA256、对应提交、完整输入、回复、流式次数与事件见[真实模型验收结果](对话重构真实模型验收结果-2026-10-19.json)。审批执行不重新调用模型；记录的耗时不作为服务延迟承诺。
- 浏览器：真实合成账号；正文 DOM 采样 50 次更新，首段只有“高等”，最终累积 125 字；桌面及 390×844 手机无横向溢出。画像和计划读取没有审批；日历提案显示标题及具体时间，点击确认后真实 API 返回一条“复习高数”提醒。
- 发现并修复的真实模型问题：具体专业示例诱发无依据套用专业；提取器把否定变成“非法学专业”；模型只用文字声称已提出待确认变更；旧计划摘要缺任务 ID；课程咨询被错误归为课表。相应用于提示词修订和服务端写入约束，而非前端删句掩盖。
- 冻结复验还发现模型抄写任务 ID 失败。新任务改用服务端短 ID；用户当前完整引用且计划中唯一的任务标题也可精确定位，不使用模糊标题或关键词猜任务。并发复核补上以原决策快照为依据的画像字段 CAS，写入与删除都保护后续修改；版本时间单调推进，避免同一时钟刻度内连续更新漏检。
- 业务闭环复核补齐：用户发言与 ANSWER 行为在本地事务内记录一次，重放不重复计数；方向选择经过既有选择、行为、资产待复核和缓存链；明确任务安排不再被“继承旧状态”覆盖；新计划不能伪造任务完成；日历变化只作废当前用户对应的日建议缓存。方向选择不走通用 undo，需明确重新选择；其余可恢复操作仍须具体确认和版本一致。
- Kev 服务 `/v1/models` 可返回，但三个 3 秒限时请求均超时；延长等待的一次合成读取意图请求耗时约 10.25 秒，服务端报告推理约 5.09 秒，并把读取判断为 chat。此结果不能证明其在当前环境效率高或准确，正式对话维持按需、限时和降级。off/shadow 设置继续生效，成功及失败边界使用确定性测试验证。

上述不是[159 个用例族](对话系统全面验收矩阵-2026-10-19.md)全部逐项通过的声明。完整矩阵还包括多模型重复评测、长期负载、真实学校授权资料、外部发布和移动设备软键盘等条件；需具备对应环境逐项执行，不能用单次模型或构建结果替代。
