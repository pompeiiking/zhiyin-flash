## 6. 缺陷与观察（只报确认项）

### P2-1（未修，R2 遗留）30 轮摘要不完整 + 多事实复述触发兜底模板
- 场景：30 轮会话后要求“总结前面聊过的关键信息，列出要点”。
- 实际：摘要只覆盖档案字段（学校/专业/年级/目标）与两条项目线索（Python 清洗 1000 行、建模校赛写代码），**未包含英语六级、每周可投入 6 小时、希望保定本地实习、12 月面试/寒假作品集等对话关键事实**；另一次多事实复述请求返回“这轮先不更新报告…这次没接住你的问题”兜底（与输入无关）。
- 预期：摘要保留目标、项目、语言/证书、时间约束等关键事实；普通复述请求不应落入报告兜底模板。
- 证据：long-summary.json、long-r3.json（recallTail）、long-recall.txt。复现：长会话 30 轮后请求总结/复述。

### P2-2（未修，R2 遗留）桌面侧栏缺少会话重命名/删除入口
- 场景：桌面 1440×900，聊天页左侧会话列表。
- 实际：侧栏会话行仅可点击切换，无重命名/删除按钮；功能仅在对话页“历史会话”面板（consult-history）与 API 可用。
- 预期：侧栏会话行提供与历史面板一致的管理入口（或明确引导）。
- 证据：main-select.json（sidebar rows=2, actions=0）、review-sessions-r3.json（历史面板 rename/delete 与 API PATCH/DELETE 均 PASS）。

1. **报告生成 4/4 成功**（R2 曾出现 2/5 失败）：本样本内失败分支未被触发；“失败提示与版本一致”仅验证到成功路径与历史上已修复的代码回归，失败分支无法强制构造，建议由 W1/后端在假模型下补测。
