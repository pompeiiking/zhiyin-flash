## 三、仍建议后续处理（未在本轮改动）

1. **全局 CSS 分层叠加**：13 个全局 CSS 全量进入口（入口 CSS 约 305KB、gzip 50KB），跨文件重复选择器 782 个、`!important` 106 处；建议 `@layer` + stylelint 收敛。
2. **入口包承载工作区壳层**：视图已全懒加载，但 `App.vue` 把命令面板/关怀弹层/侧栏/提醒嵌进入口，公开门户和登录首屏也承担；建议按 public / workspace 两套壳拆分。
3. **超大组件**：StudentView 1719 行、GradesView 1195、ConversationView 987；建议按“数据读取 / 视图 / 表单”拆组件并补组件级测试。
4. **主题/白屏兜底双实现**：`index.html` 内联脚本与 `theme.ts`/`main.ts` 两套逻辑，且内联写死颜色；建议抽公共 token 或只保留一份。
5. **token 外硬编码**：tokens.css 之外仍有约 276 个 hex 颜色。
6. **测试结构**：78 个纯逻辑单测，无组件/E2E/a11y/覆盖率门禁；建议加 Vitest 组件测试与 Playwright 关键路径。
