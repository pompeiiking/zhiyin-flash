> 版本：v1.0（待评审）

## 1. 测试目标

这轮不是把对话页点一遍，而是验证智能体在**多轮、长链路、带资产写入、模型不确定**的情况下，始终满足五条底线：

1. **听得懂**：区分讨论、询问、假设、否定、引用、明确执行，不把聊天当命令。
2. **说得对**：不越证据、不自相矛盾、不把生成过程写成诊断结论。
3. **做得对**：该写的资产写，不该写的不写；写成功后版本、状态、页面一致。
4. **记得住**：多轮上下文、会话隔离、刷新恢复、长对话不丢关键信息。
5. **扛得住**：流式中断、重复发送、模型超时、网络失败、并发请求下不脏数据、不白屏。

### 1.1 成功标准

| 维度 | 门槛 |
|---|---|
| P0/P1 缺陷 | 0 个未关闭 |
| 意图判定 | 生成/讨论/否定/假设/引用 5 类全部 100% 符合预期 |
| 资产一致性 | 对话回复、资产版本、资产正文、页面状态四者无矛盾 |
| 证据边界 | 抽样 100 条回复/报告，无“无来源写成事实”、无编造来源/分数/岗位要求 |
| 内容越界 | 报告/方向/计划正文不出现“报告里/这轮/上一版/匹配度最高”等过程点评 |
| 恢复能力 | 停止、断网、刷新、超时、重复发送 5 类场景可恢复，无重复写入 |
| 性能 | 首 token P95 ≤ 3s；普通轮次 P95 ≤ 20s；报告生成 P95 ≤ 90s |
| 安全 | 跨用户读写 0 例；提示注入不改变工具/资产行为 |

## 3. 风险地图

| 风险 | 典型表现 | 重点套件 |
|---|---|---|
| 意图误判 | “讨论更新报告”却生成；讨论任务却改状态 | INT / ACT / LOOP |
| 跨层矛盾 | 回复说不能，资产却新增；回复说已生成，版本没变 | INT / RPT / CONS |
| 证据幻觉 | 编造岗位要求、匹配度、来源链接、分数 | EVD / DIR / TOOL |
| 内容越界 | 报告结论写“报告里/这轮/上一版/没看到算法” | RPT / EVD |
| 资产污染 | 失败也落库、重复生成、旧版本覆盖、缓存脏读 | RPT / CONS / PERF |
| 上下文串台 | 跨会话带记忆、跨用户读取、删除后仍可访问 | MEM / SEC |
| 工具假成功 | 未调用工具却说已查询；图表无数据也画 | TOOL / EVD |
| 流式故障 | 重复 token、乱序、断线丢消息、刷新重复 | RES / UX |
| 提示注入 | 材料/用户消息里的“忽略规则/调用工具” | SEC / MAT |
| 性能退化 | 长对话变慢、并发重复写、报告超时 | PERF |

近期已修复、必须纳入回归的高风险点：

1. “我想讨论：更新报告”被当成生成，回复又追加“已生成”。
2. 报告结论写成“这轮能更新的是依据，不是结论”。
3. 历史报告脏数据被缓存继续返回。
4. “帮我更新计划”反而不识别。
5. “先聊聊怎么完成任务/任务完成了吗”被当成完成。

## 4. 测试策略

### 4.1 六层测试

| 层 | 内容 | 调真实模型 | 目的 |
|---|---|---|---|
| L0 静态/契约 | OpenAPI、DTO、提示词变量、事件结构 | 否 | 结构不漂 |
| L1 纯意图/规则 | `_explicit_*`、`_task_operation_intent`、工具提议 | 否 | 决策表 100% 覆盖 |
| L2 编排（假模型） | 固定假引擎输出，测落库/版本/级联/失败 | 否 | 可重复、可定位 |
| L3 单智能体（真模型） | 单环节脚本化输入 | 是 | 评内容质量 |
| L4 全链路（真模型） | 多轮从 0 到报告/方向/计划/复盘 | 是 | 评跨环节一致性 |
| L5 UI/E2E | 浏览器 + SSE + 上传 + 恢复 | 是/否 | 评用户实际看到的行为 |

### 4.2 判定依据（Oracle）

每条用例至少选 2 个，不能只看“页面有字”：

1. **回复文本**：语义断言（包含/不包含/正则），不逐字比对。
2. **服务端状态**：会话、消息、阶段、画像字段、任务状态。
3. **资产状态**：报告/方向/计划版本、正文、待核对标记。
4. **工具调用记录**：是否调用、参数、结果、是否假成功。
5. **数据库/缓存**：写入行、版本号、缓存 key。
6. **UI 状态**：DOM、可访问名称、焦点、无重复请求。
7. **日志/追踪**：无未捕获异常、无敏感信息、trace_id 可追。

### 4.3 模型不确定性处理

- 结构化用例先跑**假模型**固定输出，保证确定性。
- 真模型用例每条**重复 3 次**；P0 场景重复 5 次，1 次失败即记缺陷。
- 语义判定用“必含要点 / 必不含词 / 数值范围 / 来源可追溯”四类断言。
- 开放式回复加 **LLM judge + 人工复核**；judge 只初筛，P0 结论必须人审。
- 记录模型、温度、prompt 版本、trace_id，便于复现。
- 每条用例准备至少 2 种自然表达，防“只对测试句有效”。

### 4.4 测试技术

- 决策表：意图 = 动作词 × 讨论/否定/疑问/假设/引用 × 是否带明确执行。
- 状态迁移：五环节 × 进入/退出/回退/刷新/新会话。
- 正交组合：用户阶段 × 画像完整度 × 资料范围 × 资产状态。
- 边界值：0/1/2/200 条消息，2MB 文件，超长文本，空字段，最大版本。
- 蜕变测试：只改语气/称呼/标点，不应改变是否写入资产。
- 性质测试：任何回复不得包含 PII、内部字段名、未提供的来源。
- 故障注入：模型超时/500/空 JSON/截断 JSON/重复 SSE/DB 只读/Redis 挂。
- 安全测试：注入、越权、XSS、SSRF、路径穿越、文件类型伪装。
- 回归测试：本轮 5 个高风险点固定为 P0 回归集。

## 5. 环境、账号与数据

### 5.1 环境

| 环境 | 用途 | 要求 |
|---|---|---|
| 本地 Docker | L0-L2、UI | 固定镜像版本，记录 commit |
| 预发/测试库 | L3-L5 | 独立数据库，禁真实学生数据 |
| 真模型 | L3-L5 | 固定模型与参数；记录费用 |

### 5.2 账号矩阵

| 账号 | 特征 | 用途 |
|---|---|---|
| U1 全新 | 无画像、无会话 | 冷启动、采集、空态 |
| U2 半成品 | 有年级/专业，无报告 | 诊断触发、缺口追问 |
| U3 完整 | 画像+报告+方向+计划 | 主流程、资产级联 |
| U4 冲突 | 画像与对话矛盾 | 更正、来源优先级 |
| U5 受限 | 资料范围关闭部分来源 | 资料范围、不可见断言 |
| U6 脏数据 | 旧报告含过程点评 | 内容兜底、缓存 |
| U7 越权 | 用于 IDOR | 安全 |
| U8 并发 | 同账号双端 | 重复发送/写入 |

年级覆盖：大一、大二、大三、大四；**研究生/大五/其他阶段必须被拒绝**。  
专业覆盖：具体专业、专业大类、未填、转专业。

### 5.3 数据准备

- 固定夹具：画像 JSON、报告 V1/V2、方向三套、行动计划、任务、提醒、材料样本。
- 文件样本：TXT、CSV、TSV、HTML 复制、超 2MB、空文件、乱码、伪装扩展名、含注入文本。
- 外部事实夹具：学职平台页面、带 URL/时间的岗位要求、无来源断言、404 链接。
- 每轮用例前后执行数据清理/快照，避免历史状态污染。

## 9. 缺陷分级与准入准出

### 9.1 分级

| 级别 | 定义 | 例子 |
|---|---|---|
| P0 | 数据损坏/越权/资产错写/安全 | 讨论生成报告、跨用户读会话、失败落库 |
| P1 | 主流程错误/明显矛盾/证据越界 | 回复与资产矛盾、编造来源、报告过程点评 |
| P2 | 可恢复的功能缺陷/体验明显受损 | 错误提示不清、移动端按钮出屏 |
| P3 | 文案/样式/低频边界 | 标点、间距、空态措辞 |

### 9.2 准入

- 环境健康、账号/夹具就绪；
- 当前 commit 的 L0 全绿；
- 数据库已快照，可回滚；
- 真模型额度/开关确认。

### 9.3 准出

- P0/P1 = 0；
- P2 修复率 ≥ 95%，剩余有明确豁免；
- 311 条中 P0/P1 100% 执行，P2 抽样 ≥ 60%；
- 关键场景连续 3 次通过；
- 证据包完整、可复现。

## 10. 证据与报告

每条失败至少附：

1. 用例 ID、commit、环境、账号、时间；
2. 请求/响应（脱敏）、SSE 事件序列；
3. 会话截图、资产页面截图；
4. 资产版本/数据库查询结果；
5. 模型/trace_id、prompt 版本；
6. 复现步骤与最小输入。

日报字段：执行数、通过、失败、阻塞、P0/P1 清单、风险变化。  
最终报告：按套件统计 + 缺陷分布 + 未覆盖项 + 是否准出。

## 11. 风险与应对

| 风险 | 应对 |
|---|---|
| 模型输出不稳定 | 假模型打底；真模型重复 3 次；语义断言 |
| 真模型费用/时长 | 先跑 P0/P1，P2 抽样；固定 prompt 缓存 |
| 历史脏数据干扰 | 独立账号/库；用例前清理；脏数据单独套件 |
| 测试环境工具未配置 | 联网/学职用 mock；缺能力显式标记“未验证” |
| 并发写冲突 | 用唯一 client_msg_id；断言幂等 |
| UI 与 API 双入口不一致 | 同一用例同时走 API 与页面各一次 |

## 12. 已确认的产品口径（2026-10-18）

1. **“更新报告/更新计划”单独出现**：按明确执行处理；出现“讨论/聊聊/先说/商量/想问/咨询”等讨论句时按讨论处理，不写资产。
2. **报告生成中证据不足**：一般证据不足仍生成，相关结论标“待验证”，回复必须同时说明限制；**完全空画像且用户明确说“资料不足”时先回采集补最少信息**，不生成空报告。
3. **历史脏报告**：不自动重算、不静默改写；读取时标记“本版结论待重新生成”，由用户明确发起重新生成。
4. **图表无数据**：拒绝画图并说明缺什么；不画空图/假图。
5. **长对话超上下文**：先摘要保留关键事实；达到硬上限时提示新开会话/归档，不静默截断关键信息。
