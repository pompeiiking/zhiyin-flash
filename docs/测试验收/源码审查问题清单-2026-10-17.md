# 源码审查与遗留问题清单

分支：`codex/frontend-integration`。检查日期：2026-10-17。

范围包括仓库自有源码、接口契约、脚本、自动测试和正式前端的桌面与手机浏览器视口。依赖包、构建产物和历史设计稿不作为自有源码。按用户要求，本轮不处理学信网核验和生产部署；没有实体手机，因此移动端结论只覆盖浏览器 390×844 视口。

## 已修复问题

| S06 | 复盘调整中清空截止时间无效：空输入回填原日期 | 空值明确发送 `null`，原日期只用于并发校验快照。 |
| S07 | AI 复盘把纯日期存成无时区时间，与手动编辑契约冲突 | 纯日期按用户时区的当日结束处理，带偏移时间保持不变。历史既存数据未批量改写。 |
| R01 | AI 可能把证据缺口写成能力短板，单靠提示词不能保证稳定 | 在业务契约增加证据边界校验，并在对用户回复、报告持久化之前执行；不合规产出改走安全回退。真实模型复测中主模型的不合规 SWOT 被成功拦截，未保存错误报告。 |
| R02 | 画像、偏好、方向权重、量表、学期等表单缺少完整并发保护 | 公共 DTO 要求编辑快照；后端在状态锁内按字段合并，冲突返回最新值；画像同时校验更新时间。前后端测试覆盖五类表单。 |
| R03 | 登录过期、上传中断和长请求返回可能污染新会话或重复材料 | 认证恢复增加代际隔离，迟到响应不能写入新账号；材料编号改为账号、文件名与内容的稳定摘要，丢响应重试保持幂等；真实 HTTP 验证过期会话被拒绝和重复上传去重。 |
| R05 | 保存冲突只拒绝覆盖，缺少自动合并和草稿重放 | 后端自动合并互不相干字段；相同字段冲突保留草稿，前端展示“当前保存值 / 你的草稿”，用户确认后以最新快照重放。发生冲突时普通保存按钮停用，避免重复提交旧快照。 |
| R06 | 外部事实与 AI 生成内容边界不够硬，来源地址可能丢失 | 信息侦查员只接收已经取回的外部记录，输出地址必须精确来自输入白名单；报告只保存真实地址，不能用角色转述替代原始来源。 |
| R07 | Kev 只在当前会话启动，系统重启后不会自动恢复 | 修复启动与状态脚本，增加当前用户启动项；实际检查服务运行、模型可用。 |

## 最终检查结果

- 后端全套测试 **1000 项通过**；全库 Ruff 通过。
- 前端测试 **64 项通过**；后端契约 **85 个模型、76 个学生接口**同步；类型检查和正式构建通过。
- 生产前端依赖审计 **0 个已知漏洞**；全站 16 条学生端路由在 1440×900 和 390×844 浏览器视口均能加载对应页面，无路由错误或控制台错误。
- 真实 HTTP 表单验收 **6 项通过**，覆盖偏好、方向权重、学期、量表、材料上传幂等和过期会话拒绝，记录见[表单接口验收](遗留修复-2026-10-17/表单接口验收.json)。
- 真实 PostgreSQL 隔离验收：工作流发布 **21 项断言通过**，开发者权限 **32 项断言通过**，记录见[工作流发布并发验收](遗留修复-2026-10-17/工作流发布并发验收.json)和[开发者权限并发验收](遗留修复-2026-10-17/开发者权限并发验收.json)。
- 真实 AI 对话确认信息侦查员独立调用；主模型尝试把缺失资料写成弱项时，业务校验阻止回复和报告落库，记录见[信息侦查员真实对话](遗留修复-2026-10-17/信息侦查员真实对话.json)和[调用日志](遗留修复-2026-10-17/信息侦查员调用日志.txt)。
- 桌面浏览器和 390×844 手机视口实际检查画像更正、方向比较与权重浮层、三周用时和学期设置；各页面保持自身结构，浮层层级正常，无横向溢出，控制台无错误。
- 840 像素图标轨已实际验证侧栏文字浮层；390×844 手机视口已恢复并核对悬浮底部导航。
- `git diff --check` 通过；换行符提示来自 Windows Git 设置，不是空白错误。

## 结论

除用户明确暂缓的学信网核验、生产部署，以及当前环境无法执行的实体手机测试外，本清单中可在现有产品范围内处理的问题均已修复并有自动或实际运行证据。导师能力不是本轮可修复的现成故障；在产品闭环建立前保持关闭，避免向用户展示无服务支撑的入口。
