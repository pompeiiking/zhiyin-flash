# 正式对话页接入与检查

正式入口：`http://127.0.0.1:5275/#/chat`。采用已确认方案的对话布局，不将其复制到其他业务页。

## 本次实现

- 等待与增量正文使用同一个回复位置，移除完整回包后的逐字动画；正文和同轮引导合并，避免双回复框。
- 新增对话 SSE 接口。模型在生成过程中发送正文，结构化结果校验并完成业务处理后再显示卡片；停止接收会关闭连接，部分文字不标为完成。
- 会话、材料、选项、任务、图表、依据与画像使用现有后端接口，不以示例填充空态或错误。重试保留消息幂等标识。
- 依据以覆盖正文的小卡片呈现，入口不使用下拉箭头。右侧画像可收起，优先显示兴趣、能力、经历；手机按需打开面板。
- 历史保留在桌面导航下方，手机导航中也可打开；新回复保存来源快照，刷新和历史回读可恢复引用。
- 输入框支持多行草稿、真实材料上传、发送与停止；保留红蓝切换。修正图表失效的颜色变量，较长图表默认显示六项，其余可展开。

## 验证记录

- 前端 32 项测试通过；79 个生成类型、74 个操作与后端契约一致；生产构建通过。
- 后端相关测试 73 项通过，包含模型增量先于完成结果、并发账号隔离、取消连接、消息幂等、历史来源保留与接口契约。
- 当前本地服务真实模型联调收到 59 次正文更新。浏览器验证了等待单一占位、完成回复、停止接收、会话切换、图表生成及展开、来源读取、画像面板和品牌切换。
- 浏览器检查桌面约 1280×800、1440×900，手机 390×844、320×640，以及约 390×500 的短窗口。修复窄屏网格撑宽；检查输入区和浮层边界。浏览器未记录页面 JavaScript 错误。
