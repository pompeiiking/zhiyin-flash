# 按钮与文件导入补测

日期：2026-10-17。分支：`codex/frontend-integration`。工作目录：`C:/Users/86178/.codex/worktrees/frontend-integration/zhiyin-flash`。

本轮承接《推送前业务回归》，补测此前未在浏览器逐项操作的按钮、文件格式和异常恢复。使用本机 5287 前端、8000 后端及测试账号；保存、上传、模型生成和下载均经过当前服务。测试材料为明确构造的验收资料，不代表用户真实经历。学信网正向核验和生产部署不在本轮范围。

## 修复与复测

|问题|处理和实际验证|
|---|---|
|仅有表头的文件进入零行预览，确认无效果|在预览前拒绝空记录，说明需要添加数据；手机实际复测通过|
|JSON 数字 0 显示为空，对象字段被当成普通值|统一校验 JSON 与表格，保留零分、零绩点，拒绝对象等错误类型；零值预览、保存与列表显示通过|
|GBK 中文导出表格无法识别|增加 UTF-8、带 BOM 的 UTF-16、GB18030/GBK 解码；浏览器识别中文并实际保存|
|文件预览返回修改后，旧文件覆盖新编辑文本|预览成功后保留解码文本、清除文件选择；手机返回修改零分记录后成功保存；增加移除所选文件入口|
|导入错误的“重试”没有处理函数|编辑阶段重试识别、确认阶段重试保存；显式禁止重试的状态条不再强制显示空按钮|
|PDF、Word、压缩包错误提示都要求另存 CSV|分别提供复制文字为 TXT、扫描件识字、解压文本等准确指引；真实上传 PDF 返回新提示|
|上传失败却显示“重新读取会话”|上传错误单独展示“重新选择材料”和关闭入口；通过该按钮重选 TXT 后上传成功，手机发送并收到真实回复|
|课表容量与冲突使用打开前的旧结果|打开容量面板时重新读取；修改任务预计用时后，再次打开显示最新课程和任务占用|
|在选中阶段新增任务，默认落到第一阶段|把当前阶段传给任务编辑器；新建任务正确归入“按钮补测阶段”|
|任务菜单隐藏触发器后，手机编辑浮层定位异常|弹出编辑卡时保留触发器位置；手机拆分子任务成功，保存按钮位于可点击范围|
|方向比较写死“三个方向”|改为“已有方向”，不再与真实方案数量矛盾|
|提醒管理已有待处理记录，页头仍显示 0|页头与列表使用相同状态数据；移动端和桌面端已读、恢复后计数同步|
|已应用或仅保留记录的复盘无法修订|增加当前任务历史查看与修订入口，待确认列表增加分页；双端实际修订同一记录，旧版本保留|
|今日简报接口成功，页面却拒绝显示；缓存继续返回坏结果|为判断依据、变化记录建立明确嵌套契约；缓存使用公开字段别名；读取旧简报缓存时重新验证正文。真实生成显示成功，桌面再次读取显示“已保存的结果”|

## 文件格式与边界

|入口|实测范围|结果|
|---|---|---|
|成绩导入|JSON、CSV、TSV、TXT，桌面和手机分别预览并确认替换|8 组通过|
|课表导入|JSON、CSV、TSV、TXT，桌面和手机分别预览并确认替换|8 组通过|
|编码与字段|UTF-8 BOM、GBK、UTF-16；数字 0；中文表头；引号内逗号|浏览器与解析器测试通过；GBK、UTF-16 分别完成实际保存|
|异常导入|空文件、仅表头、未闭合引号、错误 JSON 字段类型、超 2 MB、XLSX|拒绝不合法输入，不写入空快照；本轮发现的错误已复测|
|对话材料上传|TXT、MD、CSV、TSV、JSON、HTML，双端逐一上传并移除|12 组真实上传通过|
|对话异常材料|空文件、超限文件、PDF、DOCX、XLSX、ZIP|明确拒绝；不把不支持格式标为上传成功|
|资产下载|报告、方向方案、行动计划 × PDF/Word × 桌面/手机|12 次按钮下载通过，检查 PDF 或 ZIP/Word 文件头|
|个人资料导出|个人画像 JSON、设置中的个人数据 JSON|实际下载；设置导出包含最新画像字段、成绩和课表|

操作 JSON 中记录了 15 组常规学业导入，桌面成绩 JSON 在该数组建立前单独执行，合计 16 组。不将异常拒绝、下载次数和业务功能数相加。文件头检查不等于逐页审阅 PDF/Word 排版。UTF-32、任意未知编码及所有可能损坏文件组合未作通过承诺。

## 明确限制

系统打印按钮在内置浏览器中使页面自动化等待打印流程，无法读取或操作系统打印窗口；刷新页面恢复后继续其他检查。**系统打印未判定通过**。手机检查使用浏览器视口，不能替代实体设备和软键盘验收。模型接口与渲染成功不等于对全部建议内容质量的认证。

证据见 [按钮与导入补测目录](按钮与导入补测-2026-10-17/)，包括文件操作 JSON、双端页面宽度和实际保存/浮层截图。
