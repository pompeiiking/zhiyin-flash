# open-claude-ui 适配与检查

日期：2026-10-16。工作分支：`codex/frontend-integration`；预览：`http://127.0.0.1:5287/#/chat`。

## 本轮目的

用户要求将 open-claude-ui 中适合本产品的设计与交互改造后应用到正式前端。本轮采用 frontend-design skill，以已有需求和真实后端为边界，改善公共控件与对话体验。没有给不同页面重套模板，也没有改变经典门户、报告阅读、成绩分析、日历或方向比较的布局。

参考项目：[Caho1/open-claude-ui](https://github.com/Caho1/open-claude-ui)。项目是 React 示例集合，本产品使用 Vue；本轮按交互原则重新实现，没有引入 React、Framer Motion 或整套依赖。署名与 MIT 许可随构建发布在 `public/licenses/open-claude-ui.txt`。

## 适配内容

| 参考方向 | 在产品中的落点 |
| --- | --- |
| 语义表面与细边框 | 工作区冷白、浅灰与导航背景形成层次；保留河大红蓝，选中导航使用独立表面 |
| 按钮微反馈 | 公共按钮、搜索、主色切换具备悬停、按压、键盘焦点；响应减少动态效果偏好 |
| 输入区 | 柔和阴影与聚焦反馈、44 像素发送按钮、附件移除命中区、窄屏占位文字和随宽度变化的高度 |
| 材料交互 | 拖入文件、粘贴纯文件与原文件选择器共用真实材料接口；只在服务端成功返回后显示附件 |
| 等待状态 | 唯一回复区域显示服务端进展、轻量等待动画和实际经过秒数；收到正文后原位输出 |
| 消息滚动 | 用户上翻、触控或键盘阅读立即释放自动跟随；冷却期间避免流式帧抢回位置；显式返回最新消息恢复跟随 |
| 滚动边缘 | 对话、导航、会话历史、公共浮层与面板在确有后续内容时显示轻微渐隐，监听尺寸变化并清理观察器 |
| 依据浮层 | 删除“折叠后再打开浮层”的两层入口；线索与处理记录直接打开覆盖正文的小卡片，无下拉箭头；真实图表和任务留在正文 |
| 画像分栏 | 桌面可拖动边界、方向键调宽、双击复位；Escape 取消拖动；小屏继续按需打开画像面板 |
| 分段选择 | 账号外观选择增加滑动选中底板、单一 Tab 停靠点、方向键与 Home/End 操作 |
| 命令搜索 | 增加组合框与选项语义；中文输入法确认不再触发页面跳转 |
| 复制与代码 | 回复复制就地反馈；真实回复的代码块显示语言，支持复制、长行换行与局部滚动；复制失败明确提示 |

顶栏新增全站主色快捷按钮，对话内原有重复入口移除。深色主题主按钮采用语义前景色，修正亮红底上的文字对比度。

## 保留与不适用项

已有原生面板焦点恢复、遮罩关闭、手机下拉手势、骨架屏与真实流式接口继续沿用。报告仍按其独立阅读设计呈现，课表保留时间网格，成绩保留分析图表，画像保留信息优先级；公共视觉变化不决定页面模板。

参考库中的模型选择、Token 预算、MCP 审批、桌面窗口、协作代理画布、音频、Git 差异等不属于当前学生端能力，没有添加空壳入口。附件不使用参考示例里的模拟上传；计时只表达实际等待，不伪装处理百分比或推理过程。未引入第三方品牌、远程字体和图片。

## 检查结果

- `npm test`：42 项通过，新增用户滚动优先、冷却恢复、显式回到底部、输入法确认等回归。
- `npm run check:backend`：79 个 schema、76 个学生端操作对齐。
- `npm run build`：通过。保留既有 store/system-data 同时静态和动态导入的构建提示。
- 浏览器：1440×900 与 390×844 巡检 12 个页面；补查 320×740 对话，未发现整页横向溢出或页面异常覆盖层。
- 真实联调：使用已有 student1 联调账号发送一条普通咨询，观察到单一等待区域并收到真实答复。上翻后回复完成仍停留在顶部，返回最新消息可恢复。没有用演示回复代替接口。
- 实际交互：手机和桌面线索浮层、Escape 关闭及焦点回到触发按钮；历史会话切换；画像分隔线方向键、鼠标拖动及双击；回复复制反馈；红蓝切换；深色红主题；外观分段控件方向键；搜索过滤并 Enter 跳转。
- 真实回复仍由服务端决定内容；本轮不修改模型业务决策。新增拖入/粘贴上传路径和代码片段组件已通过类型与构建检查，未将模拟材料或模拟代码回复写入业务界面；未完成所有文件类型及代码回复的端到端验证。实体手机软键盘仍需真机检查。
