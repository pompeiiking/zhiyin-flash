# 目录整理与迁移说明

整理日期：2026-10-16。

## 正式前端的位置

旧正式前端原位于 `zhiyin-src/template/zhiyin-web`，历史 Docker 配置也使用该路径。上轮系统接入删除了旧实现，但把选定的新代码留在演示目录 `redesign-demo`。本轮按用户要求，将已接入真实后端的新代码迁回旧正式目录，作为唯一前端。

保留新前端的全部运行源码、公共素材、模块入口、依赖锁文件、接口封装、测试和部署配置。未恢复旧前端实现，也未新增第二个运行版本。

## 目录职责

| 目录 | 内容 |
| --- | --- |
| `zhiyin-src/template/zhiyin-web/src` | 正式界面、接口封装和状态管理 |
| `zhiyin-src/template/zhiyin-web/public` | 正式页面公共素材 |
| `zhiyin-src/template/zhiyin-web/scripts` | 后端契约检查与类型同步 |
| `zhiyin-src/template/zhiyin-web/tests` | 前端传输与会话回归 |
| `docs/前端/需求与规范` | 用户需求基线、视觉规范 |
| `docs/前端/后端接入` | 能力清单、接口模型、接入证据和验收结果 |
| `docs/前端/开发与维护` | 启动、验证和迁移说明 |
| `docs/前端/历史设计` | 按阶段归档的设计讨论、交接与复核记录 |

README 和 AGENTS 文件保留通用文件名以便工具识别；其余迁入的文档和证据采用中文分类、中文名称。原始历史文字保留，文档开头说明其归档性质，失效的原型链接不再作为可用入口。

## 构建与路径调整

同步修改 Docker Compose、平台 Web Dockerfile、CI、发布执行器、契约生成器、模块动态加载、后端前端对齐测试和接口清单生成脚本。前端与后端契约现在位于同一工程下，契约使用相邻目录 `../contracts`，模块使用 `../zhiyin-modules`。

统一从仓库根目录作为 Docker 构建上下文。开发服务地址仍为 `http://127.0.0.1:5275`，Docker 前端仍为 `http://127.0.0.1:5173`，后端仍为 8000 端口。

## 历史资料处理

有用的 Markdown 文档已分类保留在 docs。旧设计样张的 HTML/CSS/JS、重复截图、临时探针和演示专用脚本移出仓库工作区；本机完整备份位于 `.codex/frontend-archives/27e3-structure-20261016`。备份包含原始路径映射，不应作为部署输入。临时账号和运行配置继续留在仓库外，不提交。

现有数据库、Redis 和业务记录不因目录整理而重建；接口验收状态维持原结论。

## 迁移验证

前端 12 项回归、50 项学生端接口与 69 个模型契约检查、类型检查和正式构建通过。涉及目录与文档的后端对齐检查已复验，迁入文档的相对链接检查通过。5275 开发站点、5173 Docker 站点及各自的后端代理均正常；开发服务可加载全部 4 个模块 Vue 入口。
