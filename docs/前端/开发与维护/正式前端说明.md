# 职引正式前端

当前唯一应用为仓库 `zhiyin-src/template/zhiyin-web` 中的 Vue 3 + Vite 前端。已接入后端的新前端迁回旧正式目录，替换原实现；登录、会话、个人资料及行动状态均由服务端确认。原演示目录已撤销，历史设计资料归入 `docs/前端/历史设计`。

业务基础见[完整设计文档](../../产品与架构/完整设计文档.md)。用户最新确认的视觉与交互要求见[需求基线](../需求与规范/用户需求基线.md)。接口范围与逐项证据见[后端能力清单](../后端接入/后端能力与接入清单.md)。

## 启动与验证

```sh
cd zhiyin-src/template/zhiyin-web
npm ci
npm run dev -- --port 5275
npm test
npm run build
npm run check:backend
```

开发服务将 /api 转发至 http://127.0.0.1:8000，可在本地环境文件中用 ZHIYIN_API_TARGET 配置。Docker Compose 的 web 服务使用本目录的 Dockerfile，静态站点默认在 5173，通过 nginx 转发到后端。接口凭证不写入构建产物。

十二页整合分支为 `codex/frontend-integration`，独立工作目录名为 `frontend-integration/zhiyin-flash`，使用端口 5287，避免占用逐页任务的 5275–5286。各页合并取舍及验证边界见[整合检查记录](../设计评审/十二分支整合检查-2026-10-16.md)。

普通请求必须同时满足 HTTP 成功和业务 code=0。401 或业务码 1004 结束登录态；AI 流必须收到最终 result 才算完成。切换账号后丢弃旧请求结果。仅草稿与外观偏好在浏览器保存，失败不能回落为演示数据。

## 界面与能力

|入口|职责|
|---|---|
|门户 /（兼容 /?portal=classic）|仅保留动态旧门户；新版门户及版本切换入口已移除|
|对话 /chat|真实咨询、材料、选项、行动任务、理论依据、历史会话|
|画像 /profile|读取、更正、来源与依赖、学籍信息与核验|
|成绩 /grades|独立成绩分析、文本及文件导入、预览、撤回；旧 /academic 跳转至此|
|诊断 /report；方向 /directions|完整报告、版本、方向比较和选择|
|行动 /home；阶段 /plan|真实任务、完成与恢复、资产版本|
|日历 /schedule；待办 /notes|节点、课表导入与撤回、当日建议、待办目标及建议采纳|
|资讯 /intel；复盘 /review；成长 /achievements|资讯检索、匹配、行为记录与完成记录|
|工具 /tools|已发布模块、数据、动作与工作流执行|
|账号 /settings；提醒 /reminders；指南 /guide|外观、导出、登出、提醒已读和动态帮助|
|开发者 /developer|按后端权限管理模块、版本、发布与工作流|

原前端及未选中的试验源码已经移除；历史设计证据不作为可运行前端入口。后台管理保留独立权限校验，执行器与 Worker 接口属于服务间调用。

## 测试口径

Node 测试覆盖传输错误、登录失效、跨账号旧响应、对话请求身份、取消及 SSE 完整性。后端 pytest 保留契约、领域与持久化测试，并把依赖旧画布组件文件名的检查迁移为当前前端清单、接口、品牌和无障碍基础约束。

运行根目录 scripts/acceptance/frontend/frontend-smoke.py 会新建隔离的测试账号，经过同源代理进行读写与回读验证；仅删除自己创建的测试记录，不修改已有用户数据。结果文件不保存密码或令牌。管理员写入、真实学信验证码及未发布工作流不能仅凭普通账号验收，其状态在能力清单中单列。
