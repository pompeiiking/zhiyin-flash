- 河北大学校徽蓝与官网红二选一，保留明确切换按钮；白灰配合。主操作、导航、状态及浮层均需响应主题。

- 主要信息支持与任务相关的比较、核对、修改、安排、完成或推进；次要依据和短解释使用就近小卡片。“活”指信息关系、过程和反馈可理解、可探索，不是装饰动画。

- 每次页面改动均需桌面与手机浏览器检查。截图和构建成功不能代替真实业务验证。文案自然、正式、简洁，保留设计创造空间，不给每页硬塞相同控件。

在对应工作目录的 `zhiyin-src/template/zhiyin-web` 中运行 `npm ci`，再运行 `npm run dev -- --port <本分支端口>`。访问 `http://127.0.0.1:<端口>/#<页面路由>`。新目录不复制登录凭证、环境秘密或 node_modules；各端口可能需要重新登录。默认代理后端 `http://127.0.0.1:8000`，必要时通过本地环境的 `ZHIYIN_API_TARGET` 指定服务。

现有本地后端已运行并接入真实数据；本轮对话 SSE 改动曾同步到本地容器运行环境，但 Git 工作目录不会自动部署后端。更换机器或重建服务时需按仓库运行说明加载对应源码。禁止清空既有数据库解决联调问题；多个任务共享后端时避免同时修改同一条业务数据。

只提交各自任务相关修改。公共组件、导航、主题和接口改动应记录影响与验证，汇总时逐个合并检查冲突。除用户明确授权的整合任务外，不自动合并其他页面分支。常规检查：`npm test`、`npm run check:backend`、`npm run build`，并实际验证桌面与手机的主要路径、浮层边界和失败/空态。
