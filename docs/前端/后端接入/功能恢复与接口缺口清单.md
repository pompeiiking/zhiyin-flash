# 功能恢复与接口缺口清单

更新日期：2026-10-16。

## 实施依据与状态口径

以用户确认的接入前版本 `640b01e` 为功能与交互参照，正式实现位于 `zhiyin-src/template/zhiyin-web`。本次恢复不回滚登录、数据保存、错误处理和真实服务集成，不重新启用演示数据分支。

用户要求：补回接入过程中缩水的功能与交互；所有业务数据来自真实后端；没有接口支持的功能必须保留说明并列入清单，不能直接删除。

- **已恢复**：现有接口支持，前端恢复交互，或对服务返回数据进行明确的展示计算。
- **部分恢复**：可以实现其中一部分，缺少的状态或数据不模拟；界面保留待支持入口。
- **待后端支持**：缺少契约或持久化能力。禁用业务提交或展示就近说明，不声称已经保存或执行。
- 本文不是全部接口联调记录的替代品。原有 90 项接口清单仍见[后端能力与接入清单](后端能力与接入清单.md)。

## 数据与实现约定

1. 日期倒计时按本地自然日计算，当天截止不因为午夜已过而显示逾期。完成任务不再显示逾期提示。
2. 阶段完成数来自 tasks.done，地图每个节点对应一个真实 task_id。阶段排序不代表依赖。
3. 三周节点数与任务数分别展示，不相加，避免同一事项在日历和计划重复计算。
4. 方向分数只接受后端定义的 0–1 合法值；缺失或异常值展示未知，排序放在已知值之后。五项偏好草稿不影响真实分数或方向确认。
5. 个人复盘说明使用 notes 文本保存任务关联标识及原因；界面不显示内部任务 ID。删除个人记录会同时移除对应复盘说明。受现有 notes 200 字限制，输入区保留关联标识所需长度。
6. 原选定门户、侧栏、红蓝切换、导航下方的历史会话及真实后端接入继续保留。
