# 机器人头像 · 获批造型与当前应用接入

最初V1为四位顾问的静态造型稿；`preview.html`与`preview.png`保留当时造型对照，不代表当前应用仍未接入。2026-10-15完整学生端重构继续采用用户确认的四个SVG，当前已由 `src/components/RobotAvatar.vue` 引入到应用。

| 身份 | 源造型 | 特征 |
| --- | --- | --- |
| 职业分析 | career.svg | 宽方头、单天线、蓝色面屏 |
| 行动规划 | planner.svg | 窄高切角头、顶部框架、靛蓝面屏 |

现有信息采集身份保留，使用职业分析SVG派生的圆头、浅蓝面屏及天线差异变体；它是第五独立身份，不是新获批的第五原始造型。自己与系统用中性图标。SVG保留head/eyes/mouth/antenna/body等部件；面屏柔光重复眼睛不是第二组可见眼睛。每个运行实例将paint server ID按useId隔离，部件改为data-part，避免重复DOM ID。

当前状态包括待命眨眼、思考时眼睛与天线动作、实际回复时口部与声条动作，以及真实完成后单次点头。停止、失败及静态预置不应触发完成点头。`prefers-reduced-motion: reduce`停用部件及声条动画；语义标签仍表达身份和状态。

原始造型来源：内置图像生成请求因网络错误失败，之后在项目内独立绘制矢量；未调用需要API密钥的CLI图像生成，也不宣称存在生成成功的位图稿。用户批准的是四个造型，其应用接入及动作在后续完成。
