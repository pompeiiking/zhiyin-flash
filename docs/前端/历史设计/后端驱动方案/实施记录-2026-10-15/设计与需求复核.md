## 对已标记问题的处理

| 问题 | 实现处理 |
| --- | --- |
| 对话与历史占据多列 | 咨询独立主入口；全部分类导航之后展示历史；内容区只有对话与输入，不再有第二列历史。 |
| 小浮层仍在文流或成为大弹窗 | 使用锚定浮层，桌面优先旁侧，手机就近向下展开；无整页遮罩；Esc、点击外部及关闭按钮可关闭；焦点恢复不触发滚动。 |
| 对话浮层遮住输入框 | 引用按钮移至消息末端右侧；浮层避让边界设为消息区域，正文与输入框位置不变。 |
| 信息密度偏低、整页模板化 | 画像为字段表，诊断为结论矩阵，方案为横向比较，行动为阶段清单，学业为周表，日历为月历与议程，待办为录入列表，复盘为时间线；删除多余解释卡和虚构统计。 |
| 公共导航、品牌不一致 | 全页复用一套分组侧栏与主题变量；红色主题的选中背景和浮层边框一起切换。 |
| 机器人被替换成通用图标 | 复用四个已认可 SVG 资产；闲置时不持续运动，处理状态才显示思考。 |
| 课表重复日期、遗漏课程 | 日期仅显示于表头；统一7门课程，6门排课，“专业导论”单独提示；详情不虚构教师。 |
| 导入与成绩边界错误 | 有课程、成绩粘贴入口；CSV读取预览；移除手动排课、成绩导出、导师预约、无依据的绩点换算。 |
| 行动及日期互相矛盾 | 统一10月18日方向比较、22日整理个人贡献、28日准备访谈问题；日历读取同一组任务。 |
| 待办缺删除或多出日期编辑 | 提供新增、完成/恢复、删除；不提供后端没有的就地修改文字和日期。 |
| 未读列表混入已读 | 按实际已读集合过滤；全部列表可以回看。 |
| 账号登录注册添加虚构能力 | 使用平台账号密码；删除校园统一认证、密码重置、备案号及虚构部门署名；注册错误只表达密码不一致。 |
| 工具与复盘暴露内部信息 | 移除内部编号和教务同步宣称；本地展示行动进度、完成记录；在线读取已发布目录。 |
| 全文报告缺版本入口 | 独立阅读面与章节目录；在线版本来自接口，本地只有一个实际样例版本。 |
| 图稿与前端差距 | 本次评审总览直接使用前端实拍，保留 Stitch 原图作历史参考。 |
