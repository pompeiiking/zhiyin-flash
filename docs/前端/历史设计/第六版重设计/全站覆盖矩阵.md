   状态提示（`.desk-status` 两份冲突定义，后加载者胜）、外观设置（顶栏 vs 命令面板）。
2. **弹层语言单一到失去区分度**：登录/账号/提醒/介入/命令面板/删除确认/导入/更正/更多 —— **12 处全是同一个居中 dialog**，

3. **四态在"加载"和"成功"上是空的，移动端更空**：
   零骨架屏；取数时用 `v-if` 摘掉内容而不是占位；窄屏把 `inline-status` 整条 `display:none !important`；
   成功反馈要么常驻不消失、要么静默（`setDone` 成功什么都不说）、要么在门户不可见。
4. **令牌与硬编码的账**：`--w-topbar: 60px` 与实际三处顶栏（80/76/72px）全部失配；
   `--portal-bg` 与 `--c-bg` 同屏不同源；桌面内容宽有 1180 / 1240 / 1200 三个值。
