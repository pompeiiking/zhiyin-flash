# 品牌色来源与可靠性（v6）

核查时间：2026-10-14。核查方式：**直接解码官方资产的像素统计**，不是转载、不是目测。

> 本文件的存在理由：v5 的 `tokens.css` 里写着"校徽蓝 #154494 …… 98.3% 的蓝色像素落在同一值上"，
> 但那句话**无法复现**（没说采的是哪张图），而且**与官方资产不符**。配色这种全站地基，
> 必须留下可复现的证据。于是重新测了一遍，并把这套做法固定下来。

## 一、校徽蓝（全站默认强调色）

**`#0058A7`** / `rgb(0, 88, 167)`

| 项 | 内容 |
|---|---|
| 来源 | 河北大学官网「标识系统」页的**两份正式资产** |
| ① 圆形校徽 PNG | `https://www.hbu.edu.cn/__local/2/45/CD/984479A6BA9912A333910C61D70_367FD736_3BD6.png`（187×188） |
| ② 校名标准字 PNG | `https://www.hbu.edu.cn/__local/6/6C/95/06A896DCFC69DFECAFD7D2FC6DC_139262D8_8899.png`（529×213） |
| 实测方法 | 下载原始 PNG → 纯 Node 解码（zlib + PNG 反滤波）→ 统计非背景像素的颜色分布（脚本：`_tools/png-color.mjs`） |
| 实测结果 | ① 非背景像素 **13,278** 个，其中 `#0058a7` 占 **100%**<br>② 非背景像素 **22,049** 个，其中 `#0058a7` 占 **100%** |
| 为什么是精确值 | 两份资产都是**平涂实色**：抗锯齿落在 alpha 通道上，RGB 完全不发散，所以不存在"取样误差" |
| 可靠性 | **C 级（图片像素取样）**。官方**没有**公开 VI 标准色数值；校方文字只说过校标是"深蓝色" |
| 官方文字旁证 | [跨文化传播研究中心徽标说明](http://icrc.hbu.cn/hbsm/11505.jhtml)："本徽标采用河北大学校标色彩、及外框，**沿用深蓝色**"（只有颜色名，无数值） |

### 更正记录：`#154494` → `#0058A7`

- 旧值 `#154494`（rgb 21,68,148）来源不明，实测**与官方两份资产都不符**。
- 新值取自官方资产实测，两个独立资产互相印证，且 100% 像素一致。
- 变更范围：`src/styles/tokens.css`（整套蓝色阶按新色相重排）、`docs/前端/历史设计/早期方案/早期视觉设计规范.md` frontmatter、
  `src/views/SpecView.vue`（色值表 + 对比度表）、`scripts/check-contrast.mjs` 提示语。

## 二、官网红（可切换主题强调色）

**`#96000E`** / `rgb(150, 0, 14)`

| 项 | 内容 |
|---|---|
| 来源 | `https://www.hbu.edu.cn/css/layout.css` |
| 证据 | 该文件中出现 **57 次**（含 `rgba(150,0,14,.3)` 等派生）；官网首页图标资产 `images/icon1.svg`~`icon4.svg` 的 `fill` **直接写 `#96000e`** |
| 可靠性 | **B 级（官方网页资产中的显式色值）**——不是取样，是官方自己写死的值 |
| 配套色 | 辅助金 `#EDCD88`（同批 SVG 的第二色）；副红 `#A40100`；红底浅色 `#FDF7F4` |
| 复核 | 2026-10-14 独立抓取该 CSS 复核，`#96000E` 用于 `.top` 背景、`.header.fixed` 背景、`a:hover`、边框、选中态，与记录一致 |

**注意**：河北大学**没有全校统一的公开标准色定义**——英文站用的是 `#840308` 系，
信息公开站混用 `#185688` / `#E6191B`。所以这里的"官网红"准确说法是
**中文主页的品牌红**，属于 B 级而非 A 级。

## 三、没有找到的东西（别假装有）

- **官方 VI 手册标准色数值**（CMYK / RGB / Pantone）：公网没有发布。
  官方《校徽管理办法》PDF 全文提取后**只有管理条款，无任何色彩规格**。
- **校徽矢量文件**（SVG/AI/EPS）：标识系统页只有 PNG，页内无任何矢量或压缩包下载。
  唯一官方矢量是"建校 105 周年标识"，其 `.ai` 的 XMP 色板里**只有 Illustrator 默认色板**，
  没有校方命名的标准色 —— 这本身也是"未定义标准色"的旁证。
- 第三方资源站与出版物《河北大学VI视觉形象设计》：**未采信**（非校方发布）。

> 如果将来需要 A 级依据，应向河北大学党委宣传部/艺术学院索取 VI 手册或校徽矢量授权。

## 四、对比度（全站门禁实测，`scripts/check-contrast.mjs`）

| 组合 | 比值 | 结论 |
|---|---|---|
| 白字 / 校徽蓝 `#0058a7` | **7.11:1** | 过（AAA） |
| 校徽蓝 / 白底 | **7.11:1** | 过（AAA） |
| 校徽蓝 / 页面底 `#f7f6f6` | **6.59:1** | 过 |
| 校徽蓝 / 自身浅底 `#eef5fc` | **6.47:1** | 过 |
| 深色主题亮蓝 `#6fa8dc` / `#151517` | **7.22:1** | 过 |
| 官网红 `#96000e` / 白底 | **9.12:1** | 过（AAA） |

**结论**：`#0058A7` 对白底 7.11:1 —— **主色本身就能承载文字**，
所以 `--c-primary` 与 `--c-primary-brand` 取同一个值，不需要"图形档 / 文字档"分叉。
（这是换掉旧 DeepSeek 蓝 `#4d6bfe`（4.33:1）时简化掉的那条规则，依然成立。）

## 五、复现步骤

```powershell
# 1. 取官方资产
curl.exe -sS -o "$env:TEMP\hbu-emblem.png" "https://www.hbu.edu.cn/__local/2/45/CD/984479A6BA9912A333910C61D70_367FD736_3BD6.png"
# 2. 统计主色（纯 Node，无需图形库）
node _tools/png-color.mjs "$env:TEMP\hbu-emblem.png"
# 3. 复核对比度门禁
cd zhiyin-src/template/zhiyin-web; node scripts/check-contrast.mjs
```
