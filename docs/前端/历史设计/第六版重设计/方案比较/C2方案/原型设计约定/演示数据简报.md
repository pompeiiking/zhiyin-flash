## 十一、写页面时的口径（照这 6 条执行）

1. **数字只能来自这份简报，且跨页一致**：画像「已经了解 12 条」（= 列出的 12 条，池子 15 条，缺 3 条：实习经历 / 目标岗位类型 / 薪资底线）；呈现实 46 / 要求 50；项目经历 20 / 要求 60；专业对口 88 / 要求 70；每周可投入 6 小时；投了 4 家、0 个回音；简历第一页 3 行有效信息；三条方向的匹配分 0.82 / 0.64 / 0.58，契合度 82 / 71 / 61。同一数字在两个页面不一致，比写错更糟。
2. **凡是演示内容都带标记**：报告方法写 `示例评分仅用于界面展示`；方向匹配分写 `演示预设比例，用于展示比较关系；非模型测算`；资讯来源写 `本地虚构演示资料 · 非招聘公告`；岗位数据写 `（非真实实时数据）`；成绩/课表写 `虚构的课程与成绩`。资讯页首屏、报告页页脚、学籍页导入卡各至少出现一次。
3. **禁止编造**：真实企业名、真实招聘公告、真实薪资区间、真实学信网/教务核验结论、真实导师评价，一律不写。源数据里出现的"中建某院""本地封装厂"已经是脱敏写法，照抄，不要补全成真实机构名。岗位地点、待遇、招聘期限一律写"待真实来源确认"。
4. **把握度不给数字**：界面上只出现 `依据充分` / `待验证` / `信息不足` 三档文字（0–3 格），不出现百分比、不出现"AI 置信度 92%"这类写法。方向里的小数（0.82）只用于内部比较条/排序，展示位给"匹配度较高 / 待验证"。
5. **缺口要么说清原因，要么保留为空**：取不到的资料必须写明为什么（例：实习单位评价 —— 需要实习单位出具，学校这边取不到）；没聊到的字段写 `还没聊到` 并保持 1 格把握；不得用推测填满画像。空课格不等于空闲（口径句：`空课格不代表空闲`）。
6. **一次只做一件事**：每条任务必须"什么 + 多久 + 为什么是现在"三样齐全，缺一样就不合格；提醒/干预类的浮窗一条消息只做一件事且必须自带动作（例：`排进今天` + 次要动作 `不适合，撤掉`）；归因只在 `任务太大 / 方法不对 / 方向要重估` 里选，不归到人。

## 十二、源数据无对应内容、作者需自行构造的清单

下面这些界面在 `student.ts` / `types.ts` / `demo-fixtures.ts` / `scenarios.ts` **没有**对应数据。作者需**按同一人物（陈亦然，大三，河北大学，材料科学与工程）与上面同一套口径自行构造**，并在页面上标为 `演示数据`。**不要**写成"数据来自某某界面"，也不要伪装成源数据里已有的内容。

| 界面 | 需要作者构造什么 | 必须遵守的边界 |
| --- | --- | --- |
| 登录 / 门户入口态 | 登录方式、协议文案、欢迎语、入口卡片顺序 | 不得出现真实第三方登录品牌名与真实学校统一认证地址；欢迎语只用第一节给定的人物一句话 |
| 账号设置 | 昵称、头像、手机号/邮箱、通知开关、隐私与数据授权项、注销入口 | 手机号/邮箱一律用 `138****0000`、`demo@example.com` 这类占位；不得写"已通过学信网授权" |
| 提醒（提醒中心/浮窗列表） | 除已有那 1 条提醒之外的其他条目、队列计数、免打扰时段 | 已有那条（中建某院结构岗后天 18:00 截止）照抄；新增条目一律 `kind` 用「提醒/干预/情报」三值之一，一条只做一件事且自带动作，标 `演示` |
| 工具页 | 工具清单、各工具的输入/输出示例、结果卡 | 工具产出的任何分数/结论都要标 `演示预设结果，仅用于界面展示`，`by` 写 `本地演示 · 预设结果` |
| 使用指南 | 分步说明、常见问题、术语解释（必须用用户语言，不出现内部词） | 指南里的示例人名与数字要和本简报一致；不得写真实客服渠道 |
| 设计规范 + 通用组件与状态 | 令牌表（色/字号/间距/圆角/阴影）、组件用法与禁用示例、按钮/输入/卡片/标签/空态/加载/错误态的展示矩阵 | 只描述本样张自己的样式层（`_tools/c2.css` + `_src/css/`），不要引用其他方向的令牌；空态文案要用真实缺口（如"实践证据：缺少可公开的项目资料"），不要写 lorem |
| 异常页（404 / 无权限 / 服务不可用） | 标题、说明、返回动作 | 说明里要保住口径：`本地演示数据，不代表真实服务状态`；不得写真实错误码来源系统名 |
| 岗位资讯的检索与筛选态 | 类别筛选项、搜索热词、排序 | 筛选项只能取第九节出现的 5 个 kind_label；排序文案不得暗示真实招聘平台 |
| 学籍页的冲突与缺时态 | "材料实验 vs 创新项目讨论"冲突卡、"企业参访时间待定"缺时卡 | 直接复用第六节的两条真实冲突/待定课程，不要另造课程名 |

| 首页任务卡的"直接开聊"入口 | 卡片文案 | 只能取对应年级 `taskCards` 里的原句（大三 9 条、大一 5 条、大二 5 条、大四 6 条） |
