# 当前学生端重构方向

2026-10-15。当前契约为 `../navigation-rethink/BRIEF.md` 最后的“完整产品重构”段落：独立重构整个学生端。原C2复刻基准已撤销；GenieLink与用户参考截图用于理解品质差距，不指定布局，不限制为两个核心页。分类导航保留，允许调整类下菜单；撤回的五入口及页头组内导航不再是当前方案。

## 持久化方向契约

- THESIS：精确、安静、紧凑的中文学生工作空间，以真实功能重建全站信息组织。
- OWN-WORLD：浅灰工作底、白色任务表面、克制蓝色强调、稳定分类导航与统一工作尺度；内容根据任务用途呈现，不用重复大卡片或整页文章式说明代替设计。
- STORY：当前情况 → 主要行动 → 可追溯依据；真实任务名称、状态和下一步可见，自然中性中文。
- FIRST VIEWPORT：紧凑公共壳层、共享标题/说明/操作结构，主要工作直接占据视口；短依据附近查看，长报告与资讯另有阅读安排。
- FORM：216px侧栏、56px顶栏；页标题桌面24px/手机22px，主要工作文字13–14px；浅灰底与白表面，控件8px、导航7px、任务表面12px圆角。当前Windows浏览器中文解析Microsoft YaHei。精确令牌见应用docs/前端/历史设计/早期方案/早期视觉设计规范.md与末层源码。

## 各任务的表达

画像是身份层级和对齐字段；报告是当前值/门槛刻度及语义发现；方向桌面三项并排比较；资讯是结果列表与正文阅读。今日行动以真实名称和操作组织任务，阶段计划分开目标比例与实际完成比例。日历保留完整主区宽度和当日议程，时间分析有独立面板。记录页提供紧凑新增、搜索、本页计数与按内容省略的分组；复盘原因表单先于历史证据；成长记录以里程碑与实际证据组织。

对话记录独立滚动，输入区保留在工作视口；处理状态驱动机器人动作。四个获批矢量造型继续使用，第五采集身份有独立变体，自己与系统使用中性图标。浮层支持鼠标、焦点、点击与Esc；打印提供完整正文。

覆盖分类壳层、咨询、画像、学籍、报告、方向、资讯、今日、阶段、日历、待办目标、复盘、成长及对应弹层/空白/错误/加载状态。验证范围与当前未完成项见 `../navigation-rethink/DELIVERY.md`，不能用两个页面代表全站完成。
