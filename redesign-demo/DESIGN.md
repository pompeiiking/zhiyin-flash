# 职引 · 当前学生空间设计系统

本文记录本轮已实现的界面。产品约束来自 [PRODUCT.md](PRODUCT.md)，设计方向来自 [DESIGN-BRIEF.md](DESIGN-BRIEF.md)；代码中的令牌、布局与交互是具体取值的依据。浏览器检查结果另见 [design-review/QA.md](design-review/QA.md)，本文不代替验证记录。

## 结构与阅读顺序

公开门户沿用品牌主张与蓝、红、灰色体系，本轮应用户要求增加左右构图的试稿。左侧突出主张与一个主要入口，右侧复用项目中的对话、方向依据和任务数据，提供可主动切换的三阶段示例。四句产品承诺移到首屏下沿；原版通过 ?portal=classic 保留。门户已登录入口和登录成功均进入 `/chat`，各业务页面可以独立访问。演示路由允许未登录直接打开内页并自动进入 `mid` 账号。

学生空间的常驻结构是「身份与工具条 → 页面内容 → 底部浮动书签」。顶端含职引、学生空间、搜索、年级、外观、提醒与账号；身份入口回到对话。底部始终列出「对话、任务与计划、学生档案、评估报告、复盘记录」五个文字名称；`/home` 与 `/plan` 共用任务入口，更多按钮打开场景、规范和门户。这里没有步骤编号、连线或完成顺序。

| 路由与当前组件 | 首要内容与动作 | 按需内容 |
| --- | --- | --- |
| `/chat` · `ConversationView` | 居中的对话正文、紧接正文的输入区；一次回答一个问题，可跳过 | 当前档案、聊出的任务用对话框打开；交接理由与判断依据用 details 展开 |
| `/home` · `TodayView` | 今天最小的一件事、耗时、完成与拆小；可记一件事 | 「现在要做的 / 等着的 / 已经做完的」切换任务列表；每件任务可查看原因 |
| `/profile` · `StudentView` | 姓名、学校、专业、年级与已知条数，随后是已有信息 | 来源筛选；条目内展开出处、把握与记录时间，更正用对话框；缺口与核验说明在辅助区 |
| `/report` · `AssessmentView` | 先补呈现能力的结论与 4 分差距，直接去今日任务 | 「结论与差距 / 方向对比 / 版本与变化」独立视图；分值、证据与图表默认折叠 |
| `/plan` · `RoadmapView` | 「阶段里程碑 / 本周任务 / 关键日历 / 任务来源」一次查看一类内容 | 今日任务与计划互相切换；日历选日期筛事件，来源分组可展开 |
| `/review` · `ReflectionView` | 已完成与部分推进的事实，随后为未完成任务找下一步 | 归因只能选任务、方法或方向；完成时间线与主动提醒依据可查看 |

主内容使用白色工作表面，辅助区通过位置、宽度与留白表达次要层级。正文信息和解释不会同时堆满首屏。页面引导可收起，并从账号面板恢复。

## 字体与令牌

字体为系统中文无衬线栈，优先使用 `Segoe UI`、`PingFang SC`、`Microsoft YaHei` 等本机字体；代码与规范中的等宽内容使用 `--font-mono`。无字体下载。

| 令牌 | 尺寸 | 当前用途 |
| --- | --- | --- |
| `--fs-38` | 38px | 展示与关键数字，例如报告差距 |
| `--fs-30` | 30px | 页面标题、桌面对话欢迎标题与主要任务/报告结论 |
| `--fs-20` | 20px | 节标题、品牌、手机重点标题 |
| `--fs-16` | 16px | 学生空间正文、对话、任务标题、输入内容 |
| `--fs-14` | 14px | 次要说明、来源与状态、按钮、桌面导航 |
| `--fs-12` | 12px | 注解、示例声明、手机导航等短标签 |

这是六个字号令牌。新版门户主张使用 38–68px 的响应式展示字号，示例与说明复用已有字号令牌。对话主文本在桌面和手机都保持 16px，次要说明主要为 14px；手机工具和短注解可使用 12px。工作空间默认行高 1.7，对话 1.85。字重使用 400 / 500 / 600，层级也由间距和位置承担。

颜色沿用 `tokens.css`，本轮没有新增色相。浅色默认主色 `#154494`，注意色 `#96000e`，主文字 `#1e232c`，次要文字 `#4b5157` / `#61666b`，工作表面 `#ffffff`，工作空间底色 `#f7f6f6`。这些是项目既有取值；校色出处说明保留在令牌源码中，并不等于已核实的官方 VI 标准。

深色通过语义令牌切换为 `#151517` 底、`#1b1b1d` 工作表面、`#f9fafb` 主文字，蓝/红文字相应提亮。主色可以切换河大蓝或河大红。完成记录同时给出状态文字与勾选，不只依赖颜色。

间距阶梯为 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 56 / 72px。默认圆角为控件 6 / 8px、工作表面和对话框 12px，账号头像为圆形。`plain / soft / dense` 覆盖圆角、间距与行高，字号保持不变；`workspace.css` 另有用于版式的明确像素间距。

## 布局与组件

`WorkspaceHeader` 最大宽度 1320px、桌面高 72px。常规 `.ws-page` 最大宽度 1160px、桌面水平内距 32px，底部留 132px 给浮动导航。`.ws-two-columns` 主栏与辅助栏约为 1.6:1；主要任务与报告结论用更大的留白和更短的阅读宽度形成焦点。

对话容器最大宽度 940px，按「标题 / 可滚动记录 / 输入区」三行安排。记录宽度约 36em；学生发言用浅主色底，主理发言直接阅读。输入区跟着记录区下方，支持 Enter 发送、Shift + Enter 换行，并避开中文输入法合成状态。向上读历史时不会随着逐字显示强制跟随底部。

| 共用组件 | 作用与状态 |
| --- | --- |
| `WorkspaceNav` | 当前页由 `aria-current` 与浅主色底标识；五个主入口保留名称 |
| `PageHeading` | 一个页面标题、说明和就近动作；窄屏动作换行 |
| `.ws-paper` / `.ws-aside` | 主要工作表面与辅助说明；辅助区按内容分节 |
| `.ws-subnav` / `.ws-tabs` | 页面内视图切换；当前视图由下划线或 `aria-pressed` 标识 |
| `TaskList` | 完成、恢复、等待状态；原因、采纳/否决、拆小和排进今天在任务内展开 |
| 原生 `details` | 档案来源、交接理由、报告依据、图表及辅助解释 |
| `InfoSheet` | 原生 dialog，默认最大 540px，宽版 800px；受视口限高，支持关闭按钮、Esc 与背景点击 |
| `CommandMenu` | Ctrl/Cmd + K 搜索页面、年级、外观和演示动作；方向键选择，Enter 执行 |
| `InboxSheet` / `CareSheet` | 提醒逐条处理；陪伴提醒可接受或关闭，理由按需展开 |

主要按钮最小高 42px、小按钮 36px，表单文字 16px。键盘焦点使用 `--c-focus` 的 2px 轮廓。对话记录由键盘可聚焦的 log 承载；流式回复完成时使用单独的 polite 状态区播报，避免逐字重复播报。空态给出一个可前往的动作；空白任务和档案不预填成用户的真实成果。

## 响应式、动效与打印

新版门户在 760px 以下改为单列，主要入口排在示例之前。示例由用户切换，不自动轮播；内容区域预留稳定的高度，切换只有 180ms 的入场反馈，没有离场等待。桌面主张与示例使用一次轻微入场，系统减少动效时关闭。无持续背景动画和额外媒体依赖；原版背景仅在原版页面保留。PortalView 在两版共用的顶栏插入「新版 / 原版」切换，PortalProposalView 与 PortalExample 分别实现页面与交互示例，PortalClassicView 保留原版。演示阶段同时加载两版，切换不会等待懒加载。

| 条件 | 当前重排 |
| --- | --- |
| 宽度 ≤1000px | 辅助栏缩到 270px；今日焦点动作移到下一行；三方向改为单列 |
| 宽度 ≤760px | 主辅区、报告结论与图表改为单列；顶栏高 64px；页面左右 20px；底部五个入口变为图标在上、12px 名称在下 |
| 宽度 ≤400px | 顶端边距与年级选择器进一步收紧 |
| 高度 ≤700px | 对话从固定高度改为文档流，记录区限高 50dvh，并给底部导航留空间 |

手机端保留五个主入口文字；更多入口是带无障碍名称的图标。桌面搜索按钮与「学生空间」辅助字在窄屏隐藏。档案的标签和值上下排列，版本与复盘行重排，解释不要求横向阅读。

学生空间页面切换仅使用 160ms 淡入和 6px 位移，没有离场等待；对话框 180ms 入场、进度条 200ms 变化、导航状态 160ms。换肤一次整体淡入 160ms。对话逐字显示是本地效果，时长按字数限制在 320–900ms；已有数字动画工具为 420ms。

系统 `prefers-reduced-motion` 会关闭工作空间页面、对话框与进度变化，跳过逐字显示和数字滚动；全局 CSS 将其余动画/过渡时长压到近乎即时。门户的装饰动态层直接隐藏。没有独立动效皮肤开关。

报告提供浏览器打印 / 保存 PDF。打印状态同时呈现报告、方向与版本内容，并展开用于打印的证据；打印样式隐藏常驻导航和操作工具，布局改为适合纸面的顺序。主题在打印时暂回浅色，结束后恢复。

## 数据与实现边界

`store.ts` 是 Vue reactive 单例，预置资料来自 `data/student.ts` 和四年级场景来自 `data/scenarios.ts`。没有真实模型调用、学校系统、学籍核验、岗位数据连接或业务后端；对话为关键词匹配后的本地示例。来源和核验内容说明产品流程，不表示当前已接入。

任务完成/恢复会改变任务分组及复盘中的本次记录；建议可采纳或否决，任务可拆小或加入今天；档案更正、方向选择和复盘归因都修改当前演示状态。拆小会将「投 3 家」改为「先投 1 家」，其他任务先做一个步骤，耗时改为 5 分钟。方向选择只展示影响范围，不自动重算报告、计划和里程碑。报告版本为预置快照，详细依据继续使用第 3 版。切年级会重置任务与采集进度，并替换场景标题、里程碑与复盘关注点。

登录账号与外观偏好保存至 `localStorage`，其他演示修改仅在当前页面会话内有效，刷新后恢复预置状态。引导收起也是会话状态。演示数据可以从账号面板复位。`fresh` 账号没有预置任务、历史复盘或提醒队列。

构建、颜色/字号门禁、类名门禁和实际浏览器检查的命令见 [README.md](README.md)。本轮实际浏览器 JPEG 在 `design-review/`，包括各页桌面图与对话、任务、报告手机图；操作路径使用 `public/shots/v2-*.jpg`，旧 PNG 是历史资料。本记录以当前源码为准；旧视图和外壳组件保留作参考，实际路由使用表中六个新视图。未安装 Impeccable 引擎、Git hooks 或生成图片素材。
