# 本地演示数据补充

日期：2026-10-13。分支：新前端2。改动未提交。

默认使用本地演示数据，在页面顶部和结果旁标明来源。点击「数据设置」可切换服务数据；服务模式请求失败时保留错误，不用演示结果替换。演示模式的资料导入、待办采纳、方向确认、任务完成与恢复仅更新浏览器会话，不写入业务数据库。

| 内容 | 当前数量与说明 |
| --- | --- |
| 课程 | 12 门，包括周末、重叠节次和时间待定课程 |
| 成绩 | 12 条，包括数值、优秀、良好和通过 |
| 咨询历史 | 6 段，覆盖方向、兴趣、简历、城市、复盘、家庭取舍 |
| 待办与目标 | 12 条，包含未完成与已完成记录 |
| 资讯 | 12 条，覆盖岗位、行业比较、校园活动、资料核验和求职方法 |
| 完整诊断报告 | 3 个版本，当前版 15 项分析；旧版保留当时的资料缺口 |
| 方向比较 | 3 个方向，各自包含要求、现状、建议和风险 |
| 日历节点 | 6 条，包含有日期和待定事项 |
| 预设分析结果 | 整体画像、单项深读、缺口追问、匹配矩阵、今日简报、当日建议、时间建议、待办建议、核验流程 |

数据围绕同一虚构人物陈亦然组织：材料课程与实验经历连接到项目表达任务，方向要求连接到实践证据缺口，复盘连接到时间重排。每周六小时来自示例对话中的本人说明，课表空档不被解释为实际空闲。岗位示例不使用虚构企业招聘链接或截止日期冒充真实公告；数值不是模型测算。

新用户保留空资料、空待办、空会话、空资讯和未生成报告；不会把陈亦然的优势与匹配排序作为新用户分析。旧演示会话按版本补入缺少的示例，保留已有自填记录和本地导入资料。可在账号设置中复位数据。

源码：`src/data/demo-fixtures.ts`、`src/data/demo-ai.ts`、`src/lib/demo-service.ts`、`src/lib/backend-demo.ts`。
