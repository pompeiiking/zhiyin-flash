# 四位顾问机器人头像 · 静态稿 V1

本轮仅提供静态造型预览，未替换应用头像，未实现动画。

- 职业分析：宽方头、单天线、蓝色面屏。
- 行动规划：窄高切角头、顶部框架、靛蓝面屏。
- 行动支持：宽圆头、双触点、柔和橙色面屏。
- 就业资讯：梯形头、偏置天线、侧面传感器、青色面屏。

四个SVG保留head、eyes、mouth、antenna、body等部件，供后续实现状态动作。静态稿中的重复眼睛图层仅用于面屏柔光，不是动画。

来源：内置图像生成服务请求因网络错误失败，本稿由项目内矢量代码独立绘制；没有调用需要API密钥的CLI图像生成。preview.html为造型对照，preview.png为实际浏览器导出的静态图。

按用户所说四个对话身份出稿；现有源码还登记了信息采集身份，后续接入时需统一身份数量与映射，不能悄悄删掉已有角色。
