# C2 交互原型 → Vue 演示前端

本次以 `directions/c2-hbu/index.html` 及其 CSS、`_src/app.js`、各页面行为脚本为依据，修改真实 `redesign-demo`。原型是 21 个视图组成的交互应用；没有将它当作静态图片，也没有用 iframe 替代现有前端。

当前视觉入口是 `src/styles/c2-fidelity.css`，在既有样式之后加载；具体令牌和使用方式见项目 `DESIGN.md`。门户保留。演示与服务调用、更正、会话恢复、资料导入、方向确认、任务执行、提醒及弹层继续使用现有状态与 API 入口。

## 验证与复现

在 `redesign-demo` 运行：

```text
npm.cmd run dev -- --host 127.0.0.1 --port 5199
npm.cmd run build
node scripts/check-contrast.mjs
node scripts/check-classes.mjs
node scripts/check-design.mjs --url http://127.0.0.1:5199 --no-start --json
node scripts/check-c2.mjs
node scripts/capture-c2.mjs
```

`check-c2.mjs` 验证权重排序、SPA 状态保留、候选确认、报告依据联动、画像重组、完成任务后的时间重算、待办完成、换肤与命令搜索，并检查12条学生路由在1440、1280、900、390宽度下的控制台与整页横向溢出。需要已安装 Playwright；可通过 `PW_PATH` 指定模块路径、`C2_URL` 指定服务器。

`capture-c2.mjs` 真实打开原型与 Vue 路由，按相同尺寸生成12组页面的桌面/手机配对截图。支持 `C2_ROUTES`、`C2_WIDTHS`、`C2_SHOTS`。截图作为本地评审产物，不入库。

构建、类型、对比度、现有类名检查、行为与响应式检查通过。几何检查没有学生页裁切或硬失败，公开规范页仍有两项36px按钮及可滚动步骤的建议。类名检查只覆盖其列出的原五份 CSS，不代表覆盖层全部得到静态验证。

几何检查修正了“任何内部溢出，只要存在裁切祖先就报错”的误判：现在会核对内容是否真的越过祖先边界，仍检查真正的裁切。聊天历史中旧的按钮反馈层确实溢出了行动卡，已从调用处删除。

本次独立复核先指出手机顶栏、输入区覆盖及报告/行动/计划/工具/复盘的结构差异，再按该清单修复并重拍对应画面。评审结论只对其明确复核的范围负责，不能用门禁数字替代观感。
