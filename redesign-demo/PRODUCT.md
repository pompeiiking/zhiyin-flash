# 职引 · 学生端产品约束

职引帮助大学生通过咨询看清个人情况、比较职业方向，并把选择转化为可执行任务。报告与计划提供依据，行动和持续复盘是产品目的。

本次以河北大学在读学生为演示场景，不同年级具有不同任务、里程碑与复盘重点。范围仅为独立工程 redesign-demo，后端、原前端与管理员端未修改。学生无需理解模型编排、数据契约等工程概念。

门户保留品牌主张、蓝红灰配色与原版对比，登录成功和已登录进入均首先到咨询。功能独立可达，不要求按导航顺序完成。

当前 C2 桌面目录按功能平铺分组，所有链接和图标独立可达；完整侧栏在 1024px 起为 264px，768–1023px 为 76px 图标栏，低于 768px 为底部导航与更多目录。侧栏支持整体收起与展开，内容区随之扩展。全部历史会话保留在业务导航下方，中等宽度图标栏隐藏列表但保留数据与咨询历史入口；完整桌面侧栏展开时，顶栏与侧栏页脚均提供账号入口，两者打开同一账号抽屉并共享状态；窄屏图标栏使用顶栏入口，整体收起侧栏时隐藏其页脚入口。移动为对话、行动、画像、报告快捷入口及更多目录，账号仅右上。布局与外观切换不改变内容。头部命令搜索和全部页面入口可直接访问功能。

画像与学籍、诊断与方向独立。诊断只显示结果和版本记录，方向无重复报告导航或版本选择。今日与阶段属于同一行动计划，日历独立。每页说明状态、动作和必要依据，使用正常书面语言，来源与解释按需展开。

保留咨询与会话恢复、材料与成果、画像更正与来源、学籍导入与撤回示例、诊断依据与版本、三方向比较与改选、任务完成/恢复、建议采纳/拒绝、任务拆小、里程碑、日历课表、个人待办、岗位资讯、复盘完成记录、提醒、年级/外观/导航切换与打印。归因仅为任务、方法、方向，避免对个人评价。

预置数据与模拟统计明示为示例，新账号不得冒充已有报告、学校事实或成果。UI 未接真实 API、模型、实时招聘、学校文件解析或学信网。69 schema 与 50 operation 是目录生成和校验，不是在线功能完成量。方向变化只展示影响范围，不冒充已重算；旧版记录不冒充完整旧报告，当前详细分值保持第 3 版示例。

咨询正文保持 16px，配色沿用蓝红灰语义令牌，当前学生空间以获批 c2-hbu 交互原型和实际 Vue 实现为准，设计系统见 [DESIGN.md](DESIGN.md)。最后加载的 c2-fidelity.css 统一背景、透明表面、导航、响应式和伙伴形象；演示模式提供明确标注的顾问状态预览；服务模式或实际生成时状态仍由真实思考与逐字输出字段驱动。动效用于任务位置与状态反馈，遵循减少动效偏好。方向比较的五项固定合成评分仅用于权重比较，改变权重会即时更新排序，同一SPA会话内切换路由与视图保留优先级，确认方向保持独立。当前检查为 scripts/check-c2.mjs 的行为断言与20条工作空间路由 × 1440/1280/900/390px覆盖，detect仅运行一次，结果为[]；类型、构建、对比度通过。保留门户与20条工作空间路由共对应21个原型职责，路由可达不等于完整交互状态覆盖。新增原生账号设置、提醒、登录、指南、组件状态与成长记录页；授权开关与安静时间仅为本地演示设置，不代表服务端授权或提醒调度。提醒read保留队列、later归档完整原Notice及action/deadline，可恢复队列或现在处理，done沿用原处理逻辑；三轴组织、会话缓存保存，换账号清空。咨询旧未修改预置seed迁移，不替换用户实际消息。今日与阶段统计取当前store，不冒充原型硬编码的申请或面试事实。

七档注册字号新增24px手机统计数；通用辅栏312px、咨询辅栏296px、手机底栏全宽贴底、默认浅色与C2正文栈。类名静态检查未包含两份新增覆盖样式。当前21路由三宽度的126张配对图与9张提醒操作态图（共135张）仅为本地评审证据；独立复核初次提出fix，最终七项实质修复均获2/2，7 resolved / 0 partial / 0 unresolved，不宣称逐像素相同或全部交互状态已验收。修复记录见 [C2-REPAIR-RESULT.md](design-review/v6-redesign/C2-REPAIR-RESULT.md)。V5 的 [QA.md](design-review/desktop-v5/QA.md)、V4及更早截图保留作历史参考。复盘将执行和已发生成长记录重组，周活动仍只计执行；成长六条规则保留实际条件和可读证据。报告待核对标记不更改原分数；计划逾期以明示2026-10-14演示快照为基准。本次未发布Sites。
