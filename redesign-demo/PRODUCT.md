# 职引 · 学生端产品约束

职引帮助大学生通过咨询看清个人情况、比较职业方向，并把选择转化为可执行任务。报告与计划提供依据，行动和持续复盘是产品目的。

本次以河北大学在读学生为演示场景，不同年级具有不同任务、里程碑与复盘重点。范围仅为独立工程 redesign-demo，后端、原前端与管理员端未修改。学生无需理解模型编排、数据契约等工程概念。

门户保留品牌主张、蓝红灰配色与原版对比，登录成功和已登录进入均首先到咨询。功能独立可达，不要求按导航顺序完成。

桌面咨询置顶，其余为生涯分析、计划管理、资讯与记录二级菜单，可同时展开；当前路由只补充展开所属组，保留其它组。侧栏支持整体收起与展开，内容区随之扩展，重新展开保留本次菜单状态。全部历史会话在业务导航下方；桌面侧栏展开时账号仅左下，收起时移至右上，任一状态仅一个可见入口。移动为对话、行动、画像、报告快捷入口及更多目录，账号仅右上，咨询保留历史入口。布局切换不改变内容。

画像与学籍、诊断与方向独立。诊断只显示结果和版本记录，方向无重复报告导航或版本选择。今日与阶段属于同一行动计划，日历独立。每页说明状态、动作和必要依据，使用正常书面语言，来源与解释按需展开。

保留咨询与会话恢复、材料与成果、画像更正与来源、学籍导入与撤回示例、诊断依据与版本、三方向比较与改选、任务完成/恢复、建议采纳/拒绝、任务拆小、里程碑、日历课表、个人待办、岗位资讯、复盘完成记录、提醒、年级/外观/导航切换与打印。归因仅为任务、方法、方向，避免对个人评价。

预置数据与模拟统计明示为示例，新账号不得冒充已有报告、学校事实或成果。UI 未接真实 API、模型、实时招聘、学校文件解析或学信网。69 schema 与 50 operation 是目录生成和校验，不是在线功能完成量。方向变化只展示影响范围，不冒充已重算；旧版记录不冒充完整旧报告，当前详细分值保持第 3 版示例。

正文保持 16px，配色沿用既有令牌。动效用于菜单、任务位置与状态反馈，遵循减少动效偏好。V5 以当前源码与最终浏览器截图验收，验证见 [desktop-v5/QA.md](design-review/desktop-v5/QA.md)；V4 及更早截图保留作历史参考。本次未发布 Sites。
