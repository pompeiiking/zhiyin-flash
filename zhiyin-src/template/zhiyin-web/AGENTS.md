# 正式前端维护约定

当前唯一前端位于本目录，已接入真实后端。保留用户选定界面、侧栏、动态经典门户、红蓝切换和导航下方的会话历史。用户最新指令优先。

需求与说明统一位于仓库 `docs/前端`：

- 需求：`../../../docs/前端/需求与规范/用户需求基线.md`。
- 接入清单：`../../../docs/前端/后端接入/后端能力与接入清单.md`。
- 启动与维护：`../../../docs/前端/开发与维护/正式前端说明.md`。
- 全部文档入口：`../../../docs/文档导航.md`。

历史设计用于追溯，不覆盖当前需求。统一设计语言不代表统一页面模板；不得恢复未选中的旧原型或使用演示数据冒充业务成功。接口代码接入、隔离环境验证、当前系统验证分别记录，不能把构建成功视为真实业务验收。

修改源码路径时同步 Docker、CI、模块执行器、契约生成和后端前端对齐测试。常规检查为 `npm test`、`npm run check:backend`、`npm run build`。
