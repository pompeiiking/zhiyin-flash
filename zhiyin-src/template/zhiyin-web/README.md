# 职引正式前端

本目录承载唯一运行的 Vue 3 + Vite 前端，已用接入真实后端的新界面替换旧实现。运行源码、配置、模块加载、测试和构建均以本目录为准。

- [正式前端说明](../../../docs/前端/开发与维护/正式前端说明.md)：启动、验证与页面职责。
- [完整设计文档](../../../docs/职引-完整设计文档.md)：产品与业务依据。
- [用户需求基线](../../../docs/前端/需求与规范/用户需求基线.md)：已确认的视觉与交互要求。
- [后端能力与接入清单](../../../docs/前端/后端接入/后端能力与接入清单.md)：逐项连接和验收状态。
- [文档导航](../../../docs/文档导航.md)：设计规范、历史交接及验收证据。

在本目录执行 `npm ci`，再执行 `npm run dev -- --port 5275`。开发服务通过同源代理连接本机 8000 端口；Docker 站点使用 5173 端口。

提交前执行 `npm test`、`npm run check:backend` 和 `npm run build`。历史原型与演示脚本不属于正式应用。
